# Итог: манускрипт Войнича после восьми частей исследования

Это синтезирующий документ. Он сводит воедино результаты восьми частей исследования — пяти исходных гипотез, LM-анализа, четырёх атак на дешифровку, четырёх раундов углублённой статистики и анализа внешних (физических/исторических) факторов — в единую, внутренне согласованную картину. Подробности каждой части — в соответствующих документах; здесь — сводка, таблица всех ~30 тестов и финальная интерпретация.

> **Хотите почитать как историю?** [`LONGREAD.md`](./LONGREAD.md) — единый лонгрид в восемь актов, тем же путём, но живым языком с поворотами. Этот документ — технический синтез.

## Полная таблица всех тестов

Все ~30 измерений, сгруппированных по пяти категориям. **Итог** — что тест показал относительно гипотезы «язык со смыслом».

|---|---|---|---|

| 6.H1 | Residual map по фолио | Остаток случаен (между/внутри = 0.10) — нет «трудных» страниц со смыслом | ✓ |

### Категория 4. Какая внутренняя структура есть на самом деле?

| # | Тест | Результат | Интерпретация |
|---|---|---|---|
| 1.3 | Кластеризация (silhouette, ARI) | Кластеризуется только Currier A/B (ARI 0.95); section/scribe ≈ 0 | Два режима, не темы |
| 2.D | LM cross-dialect | Кросс-CE на 0.36 бит выше собственной; A=1.81, B=1.66 | Две разные машины |
| 4.D | Позиционный профиль глифов | Чёткие слоты: инициали→середина→финали | Слоговая структура внутри слова |
| 5.G1 | Word-wrap reconstruction | **Не работает** — правый край рваный (CV=0.36) | Нюанс H1: не классический перенос |
| 6.H2 | Слоговая грамматика слова | Энтропия слотов 3.2–3.6 (низкая) — явные слоты | Слоговая система |
| 6.H2cc | Cross-check A vs B (раздельные 3-граммы) | B механичнее (1.66 vs 1.81); кросс-CE на 0.7 выше | Третье подтверждение «две машины» |

**Вердикт категории:** реальная структура — это (а) **слоговая грамматика внутри слова** (слоты) и (б) **два генеративных режима Currier A/B**. Оба — свойства *генератора*, не *языка*.

### Категория 5. Что говорят внешние данные?

| Факт | Источник | Связь с выводом |
|---|---|---|
| C14: пергамент 1404–1435, однородный (4 образца) | UA 2009 | Если имитация — то профессиональная, в XV в. |
| Iron gall ink один для текста и рисунков; анахронизмов нет | McCrone 2009 | Текст и иллюстрации контемпоранны |

| Timm/Schinner (2020): self-citation = имитация | Cryptologia | Наша H5 опровергает *их механизм*, G3 подтверждает *тезис* иным механизмом |

**Вердикт категории:** внешние данные **не противоречат** ни одному внутреннему выводу и **усиливают** несколько (подлинность материалов, отсутствие ключа исторически, «режимы вместо авторов»).

## Финальная интерпретация

После ~30 тестов в восьми частях, охватывающих внутреннюю статистику текста (раунды 1–7) и внешние физические/исторические факторы (часть 8), картина внутренне замкнута и согласована:

> **Манускрипт Войнича — это профессионально исполненная в начале XV века имитация письменности.** Текст порождается локальной слоговой генерацией с порядком памяти 1–2 глифа (минимальная 3-граммная модель воспроизводит всю наблюдаемую статистику с ошибкой 0.9%). Рукопись содержит переключение между двумя статистически различными генеративными режимами (Currier A/B — две разные «машины», не два автора и не две темы). Строки не выравнивались по правому краю жадным word-wrap'ом. В тексте нет синтаксиса, нет семантической структуры (верхняя граница смысла ≤0.02 бит/глиф, в 75 раз ниже естественного языка), нет шифра или номенклатора к латыни, итальянскому или английскому, и нет внешнего ключа, который был бы доступен исторически.

Это не «доказательство, что смысла нет» — такую нулевую гипотезу доказать нельзя. Это **баланс улик**: ни один из ~30 тестов не обнаружил свойства, требующего смысла для своего объяснения, тогда как несколько измерений (information bound, cross-ppl, 3-граммная достаточность) делают «язык со смыслом» количественно неправдоподобным.

### Единственный логически открытый остаток

Смысл, закодированный **полностью вне** доступной нам информации: конкретный экземпляр рукописи служил физической шифр-подушкой, а «чтение» требовало отдельного несохранившегося документа-ключа. Но это гипотеза о внешнем объекте, которого у нас нет, — и как таковая она **нефальсифицируема** ни внутренней статистикой текста, ни внешними физическими измерениями (C14, чернила), которые уже сделаны. С точки зрения всего, что *доступно измерению*, рукопись — имитация.

### Что наша работа добавляет к существующей литературе

1. **Уточнение механизма Timm & Schinner (2020).** Их «hoax hypothesis» через self-citation — самое авторитетное современное подтверждение имитации. Но их *конкретный алгоритм* наша исходная H5 опровергает количественно (self-citation Войнича 0.97×, слабее всех живых языков). Наш G3 подтверждает *тезис* имитации, но через *другой, работающий механизм* — слоговую 3-грамму. Это новый вклад: тезис верен, предложенный механизм — нет.

2. **Количественная граница смысла (H4).** Впервые за всю историю исследований дана измеримая верхняя оценка того, сколько семантической информации *могло бы* быть в тексте: ≤0.02 бит/глиф. Это переводит вердикт «нет смысла» из качественного в количественный.

3. **Строгая генеративная модель (G3).** Не просто «имитация», а конкретная, минимальная, фальсифицируемая модель: 3-грамма глифов порядка памяти 1–2. Любой будущий тест, нашедший метрику, которую эта модель *не* воспроизводит, фальсифицирует её — но за 8 частей такого теста не нашлось.

4. **Currier A/B как генеративные режимы, а не авторы.** Синтез Davis (5 писцов, 2021) + критики 2025 (1 рука, 5 меток) + нашей статистики (LM cross-dialect, cross-3gram): устойчивое деление — это A/B, и оно лучше всего интерпретируется как переключение режимов одной мастерской, а не смена писцов.

## Воспроизводимость

Весь код — в [`voynich_lm/`](./voynich_lm/) (16 аналитических модулей). Полный прогон:

```bash
python fetch_data.py                  # транскрипция + 4 контрольных текста
python -m voi.run_all                 # пять исходных гипотез
python -m voynich_lm.run_experiments  # LM-семейство + анализы A–G
python -m voynich_lm.analyze.round4   # Ципф/MI/Марков/PPMI/drift
python -m voynich_lm.analyze.round5   # word-wrap/PACF/generative sufficiency
python -m voynich_lm.analyze.round6   # residual/information bound/signatures
python -m voynich_lm.analyze.round7   # поиск внешнего ключа
```

Все числа сохранены в `results.json`, `results_lm.json`, `round4_results.json`, …, `round7_results.json`. Графики — в [`figures/`](./figures/).
