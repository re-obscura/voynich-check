# voynich-check

> Пять проверяемых гипотез о манускрипте Войнича — и ни одна не пережила контрольный тест.

Независимое статистическое воспроизведение: берём транскрипцию Такахаши (EVA, формат IVTFF 2.0), прогоняем пять конкретных гипотез о природе текста и в каждой ставим контрольную проверку — то, что обычно пропускают, обрадовавшись первому красивому числу.

Полный разбор — в [`ARTICLE.md`](./ARTICLE.md). Код — полностью воспроизводимый: один скрипт качает данные, другой прогоняет все пять гипотез.

---

## TL;DR — что проверялось и чем кончилось

| # | Гипотеза | Контрольный тест | Итог |
|---|---|---|---|
| 1 | Текст рядом с иллюстрацией описывает иллюстрацию | Монте-Карло по верху/низу страницы | ❌ Это вёрстка, а не смысл |
| 2 | Текст собран из шаблонных блоков | Поиск 4-грамм на ≥3 тетрадях | ❌ Не найдено ни одного |
| 3 | Различия секций — это просто разные писцы | silhouette / ARI / перестановки | ❌ Кластеризуется только Currier A/B |
| 4 | Если это язык, есть синтаксис | Биграммы vs униграммы в LOO | ❌ Порядок слов не помогает |
| 5 | Самоцитирование по Тимму/Шиннеру | Сравнение с 4 живыми языками | ❌ Слабее всех контрольных |

**Баланс улик:** ни один тест не нашёл свойства, несовместимого с текстом, сгенерированным без семантики; сразу несколько наблюдений плохо совместимы с настоящим языком.

## Ключевые числа (из независимой репликации)

Корпус: **183 фолио · 4183 строки · 31 005 токенов · 7181 уникальное слово · 22 глифа**.

| Метрика | Значение | Что значит |
|---|---|---|
| H₂\|₁ (условная энтропия глифов) | **2.138 бит** | Глифы сверхпредсказуемы (живые языки 3.0+) |
| Суффикс `-am`: конец строки vs середина | **11.5% vs 0.60%** | Line-edge эффект, в 19× сильнее |
| JSD(край строки vs середина) | **0.536** | Эффект края строки реален |
| 4-граммы на ≥3 тетрадях (bio/recipes/herbal) | **0 / 0 / 0** | Шаблонной генерации нет |
| Currier A/B: silhouette / ARI | **+0.041 / 0.954** | Единственное деление, что кластеризуется |
| section / scribe: silhouette | **+0.021 / +0.018** | ≈0, не кластеризуются |
| LOO униграммы vs биграммы | **89.3% vs 69.5%** | Порядок слов не несёт информации |
| Жаккар топ-20 биграмм между секциями | **0.00–0.11** | Секции различает набор слов, не порядок |
| Self-citation: Войнич vs контрольные | **0.97× vs 1.34–1.91×** | Слабее всех живых языков |
| Hapax legomena: self-citation | **ровно 0** | Механизм копирования не работает |

## Быстрый старт

```bash
git clone https://github.com/re-obscura/voynich-check.git
cd voynich-check

python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python fetch_data.py        # качает транскрипцию + 4 контрольных текста в ./data/
python -m voi.run_all       # прогоняет все 5 гипотез, пишет results.json
```

Полный прогон занимает ~1 минуту (основное — UMAP в гипотезе 3). Никаких данных в репозитории нет — всё тянется с voynich.nu и Project Gutenberg при первом запуске.

### Отдельные гипотезы

Каждую можно прогнать независимо:

```bash
python -m voi.entropy        # матчасть + условная энтропия H₂|₁
python -m voi.h1_position    # позиция в абзаце / line-edge
python -m voi.h2_ngrams      # шаблонные блоки / TTR
python -m voi.h3_cluster     # кластеризация Currier/секция/писец
python -m voi.h4_syntax      # синтаксис: би- vs униграммы
python -m voi.h5_selfcite    # самоцитирование Тимм/Шиннер
```

## Методология

- **Что считается»** — конкретный, воспроизводимый показатель для каждой гипотезы.
- **Контроль** — Монте-Карло (1000–2000 итераций), перестановочные тесты, сравнение с живыми языками.
- **Метрики:** JSD, TF-IDF + косинусное сходство, silhouette score, adjusted Rand index (ARI), критерий Манна–Уитни, MultinomialNB leave-one-folio-out, UMAP + K-means.

Точные значения чувствительны к составу корпуса и параметрам (окно UMAP, α сглаживания, способ агрегации JSD). В статье решения «гипотеза подтвердилась / нет» принимаются по **направлению эффекта и порядку величины**, а не по третьему знаку после запятой.
